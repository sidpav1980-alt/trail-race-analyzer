# Trail Race Analyzer v0.97 OFFLINE

Изменена логика темпа по участкам.

- В таблице теперь показывается **Рекомендуемый темп**, а не максимально возможный.
- За основу берётся **средний прогнозный темп всей гонки** после VO₂max / HR / длительности.
- Рельеф лишь умеренно сдвигает темп:
  - подъёмы медленнее;
  - спуски немного быстрее;
  - без экстремального ускорения в начале.
- Добавлен небольшой negative-split bias:
  - первая треть чуть спокойнее;
  - середина около среднего;
  - последняя треть лишь немного быстрее при подходящем рельефе.
- Все участки нормируются так, чтобы их суммарное время точно совпадало с общим прогнозом движения.

Цель — избежать раскладки вида «очень быстро первые 20–25 км, затем 9–10 мин/км».
