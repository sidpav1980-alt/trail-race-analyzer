## v0.25
- Исправлены цвета кнопок загрузки во всех офлайн-разделах.
- Во время обработки кнопка становится серой.
- После успешной обработки кнопка становится зелёной и остаётся зелёной.
- При ошибке кнопка становится красной и остаётся красной.
- После выбора нового файла кнопка снова становится синей.
- CSS исправлен так, чтобы состояние `disabled` больше не перекрывало цвет обработки/ошибки.

Зелёная — успешно.
