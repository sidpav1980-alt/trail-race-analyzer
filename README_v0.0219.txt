v0.0219

Добавлено в симуляцию:
- Новое случайное событие «Нашли аптечку» — аптечка появляется и остаётся до конца гонки.
- Новое случайное событие «Нашли фонарик» — фонарик появляется и остаётся до конца гонки.
- Новое событие «Ночь»:
  - фонарик есть -> +0:00;
  - фонарика нет -> +5:00.
- Гарантированное экипировочное событие теперь выбирается из 4 вариантов:
  1. Поранился -> аптечка;
  2. Дождь -> мембранка;
  3. Жара -> вода;
  4. Ночь -> фонарик.
- Минимум одно из этих четырёх событий обязательно присутствует в каждой гонке.
