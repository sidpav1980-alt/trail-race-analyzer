# Trail Race Analyzer v0.48 ONLINE FULL

## v0.48
- Исправлена загрузка собственного ITRA по ссылке вида:
  `https://itra.run/RunnerSpace/sidorenko.pavel.1840251`.
- Из старого формата ссылки автоматически извлекаются slug и Runner ID.
- Дополнительно строится современный кандидат URL вида:
  `/RunnerSpace/SIDORENKO.Pavel/1840251`.
- Если RunnerSpace загружает данные через внутренний `api/RunnerSpace/GetRunnerSpace`,
  сервер пытается найти этот endpoint в HTML и получить PI оттуда.
- Если Runner ID/ссылка указаны, ФИО не требуется и обычный поиск по ФИО не запускается первым.
- ITRA PI по умолчанию остаётся 0.

### Анализ карты / броды
- Отменена логика «если рядом отмечен мост — не считать бродом».
- Удалена проверка `bridge=yes`, так как она усложняла анализ карты и могла ломать загрузку.
- Броды снова определяются только как короткие пересечения водного участка.
- Километраж бродов сохраняется.

# Trail Race Analyzer v0.46 ONLINE FULL

## v0.46
- Броды теперь показываются не только количеством, но и километражем: например `2.4, 11.7 км`.
- Если в OSM рядом с пересечением отмечен мост (`bridge=yes`), такое пересечение не считается бродом.
- Длинные участки движения вдоль воды по-прежнему не считаются бродом.
- Если указан ITRA Runner ID или ссылка на профиль, для «Загрузить мой ITRA» ФИО больше не обязательно.
- При указанном Runner ID поиск сначала выполняется именно по ID/ссылке, без запроса ФИО.
- ITRA PI по умолчанию теперь **0**.

Важно: определение бродов зависит от полноты OSM. Не отмеченный в OSM мост приложение не сможет исключить автоматически.

# Trail Race Analyzer v0.45 ONLINE FULL

## v0.45
- В «Анализ карты» добавлен показатель **Броды**.
- Приложение считает отдельные короткие пересечения участков, классифицированных OSM как вода/река.
- Несколько соседних точек воды объединяются в один брод.
- Длинный участок вдоль воды (>300 м) автоматически не считается бродом.
- При выборе нового GPX счётчик бродов очищается вместе с остальным анализом покрытия.
- Это оценка по данным OSM, а не гарантия фактического брода на местности.

- `OPENROUTER_MODEL` = `openrouter/free`;
