v0.0218
1. Проверка экипировки обязательна перед стартом.
2. Без проверки симуляция не запускается: «Пройдите проверку экипировки перед стартом».
3. Кнопка «Проверить» работает один раз на одну гонку и затем блокируется.
4. После сброса/новой гонки проверка снова доступна.
5. В каждой симуляции гарантировано минимум одно событие экипировки:
   - Поранился → аптечка;
   - Дождь → мембранка;
   - Жара → вода.
6. Если нужная вещь отсутствует — +5 минут; если есть — 0 минут.
