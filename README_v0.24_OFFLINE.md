## Цвета кнопок загрузки

- **Серая** — файл ещё не выбран или выполняется обработка.
- **Синяя** — файл выбран, можно запускать обработку.
- **Зелёная** — файл успешно обработан.
- **Красная** — произошла ошибка.

При выборе нового файла кнопка снова становится синей.

## Офлайн-режим

Без интернета доступны:
- загрузка и обработка GPX;
- тренировки;
- стартовый список XLSX/CSV;
- локальные расчёты;
- прогноз результата;
- анализ загруженных данных.

Онлайн-поиск ITRA/OpenRouter в этой сборке отсутствует.
