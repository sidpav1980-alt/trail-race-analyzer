# Текущая логика расчётов

## ITRA Km-effort
`Km-effort = дистанция, км + набор, м / 100`

## ITRA Endurance Points
- 0: 0–24 Km-effort
- 1: 25–44
- 2: 45–74
- 3: 75–114
- 4: 115–154
- 5: 155–209
- 6: 210+

## Trail Difficulty 0–10
Отдельная внутренняя оценка сложности рельефа GPX:
- 0–2: почти плоская;
- 3–4: лёгкий трейл;
- 5–6: средний;
- 7–8: тяжёлый;
- 9–10: очень тяжёлый / альпийский.

## Поправка времени по набору
`+1000 м набора = +1 час`

Неполная тысяча считается пропорционально.

# Цвета кнопок
- **Серая** — файл не выбран.
- **Синяя** — файл выбран и готов к обработке.
- **Серая** — идёт обработка.
- **Зелёная** — успешно обработано.
- **Красная** — ошибка.
- При выборе нового файла кнопка снова становится синей.
