# Trail Race Analyzer v0.0234

Исправление DNF при демотивации:
- DNF теперь срабатывает после 3 отрицательных событий за одну гонку.
- Нейтральное событие 0:00 больше не сбрасывает счётчик.
- Положительное событие также не стирает уже накопленные отрицательные события.
- При третьем отрицательном событии симуляция сразу останавливается с DNF.
- Остальная логика v0.0233 сохранена.
