# Trail Runner: Armageddon v5

Игровая сборка — только экран симуляции и игровые панели.

Изменения v5:
- визуальная скорость всех режимов ускорена в 1,5 раза относительно исходных режимов: 60× / 90× / 120× / 150×; расчёт и результат гонки не меняются;
- расширен блок «Текущая экипировка» прямо на экране гонки;
- видны предмет, уровень 1–5, прочность и эффект;
- показаны все слоты: кроссовки, рюкзак/жилет, мембранка, фонарь, палки, часы, аптечка и вода;
- пустые слоты явно обозначены;
- расходники сохранены отдельно: гели, батарейки/аккумулятор, бинт, марля, перекись, пластырь, крем;
- у кроссовок отображается уровень и бонус скорости;
- визуальный экран сохранён: профиль + бегун + группы соперников + события под ним.
