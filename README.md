# Прогноз и анализ трейловых гонок — v0.56 OFFLINE SIM

Офлайн-сборка без Docker.

## Новое: 5. Симуляция гонки
После расчёта прогноза можно запустить анимированную симуляцию прохождения трассы.

- Бегун движется по профилю GPX.
- В каждой симуляции случайно выбираются 4–8 событий из пула 20 событий.
- События могут добавить или отыграть время.
- События не меняют основной прогноз — это отдельная развлекательная симуляция.
- Работает полностью офлайн.
