# Trail Race Analyzer v0.0240

В виртуальном режиме добавлен чемпионат из трёх последовательных уровней.

Уровни:
1. 20 км, +500 м. Профиль как раньше: 0–3 км вверх +500 м, 3–7 км вниз, дальше ровно. ПП на 14 км.
2. 60 км, +2500 м, 4 ПП.
3. 100 км, +6000 м, 5 ПП.

Правила:
- В начале чемпионата 3 жизни.
- Каждая новая попытка виртуального уровня расходует 1 жизнь.
- Уровень засчитывается только при первом месте по существующей логике симуляции.
- При первом месте жизни восстанавливаются до 3 и открывается следующий уровень.
- Если три уровня пройдены, появляется надпись «ТЫ ЧЕМПИОН!».
- При 0 жизней новый старт блокируется до перезапуска чемпионата.
- В режиме реального трека уровни и жизни не действуют и панель чемпионата скрыта.
