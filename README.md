# Trail Runner: Armageddon

Трейловая гоночная симуляция с прогнозом прохождения трассы, экипировкой, усталостью, случайными событиями, соперниками и виртуальным прогрессом.

- Полностью удалены регистрация и авторизация.
- Игра открывается сразу без создания профиля.
- Прогресс хранится локально в браузере устройства.

## Другие реализованные механики проекта

- Симуляция трейловой гонки по дистанции.
- Обязательная экипировка и проверка перед стартом.
- Кроссовки, рюкзак/жилет, вода, мембранка, фонарь и другие предметы.
- Усталость и состояние спортсмена.
- При усталости 0 отдых не должен запускаться как отдельное действие.
- Случайные события с временными штрафами/бонусами.
- Погодные события.
- Питание и вода.
- Покрытие трассы и технические участки.
- Броды.
- Мотивация/демотивация и игровые последствия.
- Текущая позиция и лидеры гонки.
- Награды и игровая экономика.
- Экран помощи.
- Адаптация интерфейса для мобильного браузера/iPhone.
