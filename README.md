# Trail Race Analyzer v0.0232

Основа: v0.0231.

Добавлено только два изменения:

1. DNF при демотивации
- считаются все отрицательные события за текущую гонку;
- события 0:00 и положительные события счётчик не сбрасывают;
- на третьем отрицательном событии симуляция сразу завершается DNF.

2. Упрощён виртуальный профиль 20 км
- 0–3 км: ровный подъём, суммарно +500 м;
- 3–7 км: ровный спуск обратно;
- 7–20 км: ровный участок до финиша;
- два виртуальных брода из v0.0231 сохранены: 6.0 и 14.0 км.

Остальная логика v0.0231 не менялась.
