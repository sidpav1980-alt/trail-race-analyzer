# v1.00

- Миша с топором на старте теперь показывается полные 3 секунды при любой скорости симуляции, включая 4×.
- Сама симуляция начинает движение только после окончания стартовой 3-секундной заставки.
- Случайные события выбираются сбалансированно: примерно 50% отрицательных и 50% положительных.
- При нечётном количестве событий дополнительная сторона выбирается случайно; при активной удаче дополнительный слот положительный.
- Редкая случайная встреча с Мишей заменяет положительный слот и не увеличивает число негативных событий.
- Остальная логика v0.99, включая непрерываемый анализ карты, сохранена.
