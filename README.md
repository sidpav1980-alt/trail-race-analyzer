# v0.0217 — обязательная экипировка в симуляции

- Над блоком «СИМУЛЯЦИЯ ГОНКИ» добавлена строка обязательной экипировки:
  аптечка, вода, мембранка, фонарик.
- Кнопка «Проверить» случайно определяет наличие экипировки.
- Одновременно может отсутствовать максимум 2 предмета.
- Аптечка, вода и мембранка хранятся как отдельные переменные состояния симуляции.
- При проверке показывается иллюстрация: лиса и сова за столом проверяют снаряжение.
- Добавлено событие «🩸 Поранился»:
  - если аптечка есть — +0:00;
  - если аптечки нет — +5:00 к финишному времени.
- Исходный прогноз не меняется; всё влияет только на текущую симуляцию.

- Событие «🌧️ Дождь»: мембранка есть — 0:00; нет — +5:00.
- Событие «☀️ Жара»: вода есть — 0:00; нет — +5:00.
