# Trail Runner: Armageddon v6 — профили игроков

Добавлено:
- регистрация по нику и паролю;
- вход по нику и паролю;
- максимум 50 игроков;
- отдельный прогресс каждого игрока;
- автоматическое сохранение денег, XP, уровня, экипировки, прочности, расходников, усталости и пройденных гонок;
- восстановление прогресса после входа на другом устройстве;
- пароли хранятся только как хеши в SQLite.

Запуск:
`pip install -r requirements.txt`
`python server.py`

Для Timeweb/Render:
`gunicorn -w 2 -b 0.0.0.0:$PORT server:app`

Переменные:
- `SECRET_KEY` — обязательно задайте случайную длинную строку.
- `TRAIL_GAME_DB=/data/trail_players.sqlite3` — путь к БД на постоянном диске.
- `SESSION_COOKIE_SECURE=1` — при HTTPS.

## v7
- Все основные категории экипировки расширены до 7 уровней.
- В магазине уровень вещи показывается как `ур. N/7`.
- Добавлен отдельный расходник «Сменный аккумулятор фонаря».
- Фонари 5–7 уровней работают от аккумулятора.
- Разряженный фонарь можно восстановить сменным аккумулятором или powerbank.
- LEKI уровней 6–7 дают более сильный скоростной бонус.
- Сохранения старых профилей v6 совместимы: новые ресурсы добавляются автоматически.

## v8
- Убрана обязательная проверка экипировки перед стартом.
- После входа ник отображается сверху рядом с иконкой профиля.
- Добавлена отдельная кнопка «Выйти» в шапке; выход также остаётся в карточке профиля.
- После успешной регистрации показывается сообщение «Профиль создан» перед входом в игру.

## v9
- Вода добавлена как покупаемый расходник по 0,5 л.
- Начиная с 4 уровня вода обязательна для старта.
- Требуемый запас воды зависит от длительности, температуры и уровня солнца.
- Добавлены погода и уровень солнца для каждой гонки.
- Высокое солнце увеличивает расход воды и может добавлять временной штраф.
- При холоде/дожде мембранка обязательна. Без рабочей мембранки старт блокируется; при потере защиты на трассе возможно переохлаждение и DNF.
