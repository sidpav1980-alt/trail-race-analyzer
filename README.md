# Прогноз и анализ трейловых гонок — v0.66

Изменения симуляции:
- за одну гонку больше не могут произойти все случайные события;
- каждый запуск выбирает только небольшую случайную часть пула;
- чем длиннее прогнозируемая гонка, тем больше событий:
  - <1 ч: 0–1;
  - 1–2 ч: 1;
  - 2–4 ч: 1–3;
  - 4–6 ч: 2–4;
  - 6–10 ч: 3–6;
  - 10–15 ч: 5–8;
  - >15 ч: 6–10;
- максимум 10 событий за одну симуляцию;
- сохраняется ограничение не чаще 2 событий в час;
- минимальный интервал между событиями остаётся 30 минут виртуального времени.
