# v0.0215 — случайное время событий

Изменения относительно v0.0214:
- События больше не распределяются равномерно по гонке: момент каждого события выбирается случайно.
- Птица, кошка, лиса и сова при успешном тапе дают бонус −3 минуты к финишному времени (не −3 секунды).
- Остальная логика v0.0214 сохранена.
