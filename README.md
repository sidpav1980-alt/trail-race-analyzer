# Trail Runner: Armageddon v6 — профили игроков

Добавлено:
- регистрация по нику и паролю;
- вход по нику и паролю;
- максимум 50 игроков;
- отдельный прогресс каждого игрока;
- автоматическое сохранение денег, XP, уровня, экипировки, прочности, расходников, усталости и пройденных гонок;
- восстановление прогресса после входа на другом устройстве;
- пароли хранятся только как хеши в SQLite.

Запуск:
`pip install -r requirements.txt`
`python server.py`

Для Timeweb/Render:
`gunicorn -w 2 -b 0.0.0.0:$PORT server:app`

Переменные:
- `SECRET_KEY` — обязательно задайте случайную длинную строку.
- `TRAIL_GAME_DB=/data/trail_players.sqlite3` — путь к БД на постоянном диске.
- `SESSION_COOKIE_SECURE=1` — при HTTPS.

## v7
- Все основные категории экипировки расширены до 7 уровней.
- В магазине уровень вещи показывается как `ур. N/7`.
- Добавлен отдельный расходник «Сменный аккумулятор фонаря».
- Фонари 5–7 уровней работают от аккумулятора.
