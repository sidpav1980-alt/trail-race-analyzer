# Trail Race Analyzer v0.0227

Изменения в симуляции:
- Для всех событий, связанных с экипировкой, теперь выводится явное сообщение о результате проверки.
- Поранился:
  - аптечка есть -> «травма обработана -> штраф 0:00»;
  - аптечки нет -> «штраф +5:00».
- Дождь:
  - мембранка есть -> «штраф 0:00»;
  - мембранки нет -> «штраф +5:00».
- Жара:
  - вода есть -> «штраф 0:00»;
  - воды нет -> «штраф +5:00».
- Ночь:
  - фонарик есть -> «штраф 0:00»;
  - фонарика нет -> «штраф +5:00».
- «Нашли аптечку» и «Нашли фонарик» также показывают явный результат.
- Текст выводится во всплывающем уведомлении, карточке события и журнале событий.
- В архиве один README.md.


## v0.0228 — броды
- Броды на первых 200 м трассы не учитываются.
- Точки брода в пределах 400 м объединяются в один брод.
- Исправлено прежнее объединение по 500 м.


## v0.0229 — ложные броды в городе
- Если GPX идёт по OSM-дороге/асфальту, простое геометрическое пересечение с водой больше не считается бродом.
- На дороге брод учитывается только при явной OSM-метке ford.
- Мосты по-прежнему исключаются.
- Первые 200 м не учитываются.
- Броды в пределах 400 м объединяются.
