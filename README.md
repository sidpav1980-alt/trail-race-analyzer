# Trail Runner: Armageddon v2

Добавлено:
- покупка и расход гелей; на длинной гонке их может не хватить;
- фонари 1–4 уровня работают на батарейках, которые нужно покупать;
- фонарь 5 уровня работает на аккумуляторе и может заряжаться от переносного аккумулятора;
- палки ломаются; LEKI дают дополнительный бонус скорости;
- аптечка состоит из бинта, марли, перекиси, пластыря и крема от натирания;
- случайные травмы используют содержимое аптечки;
- перелом ноги = DNF;
- высокая усталость и частые старты увеличивают вероятность перелома;
- введён показатель усталости;
- отдых длится 5 реальных минут и блокирует старт на это время.

Остались 20 уровней, уровень трейлраннера 1–100, рубли, магазин, износ экипировки и финал «Армагеддон 1000».
