# Trail Race Analyzer v0.0232

Основа: загруженная v0.0231.

Изменение:
- В симуляции добавлена кнопка «Симуляция реального трека».
- Реальный загруженный GPX используется в симуляции только после нажатия этой кнопки.
- Кнопка «Симуляция трека 20 км» по-прежнему выбирает виртуальный трек.
- При выборе нового GPX текущая симуляция и выбранный источник сбрасываются.
- Для запуска реального трека нужен загруженный GPX и рассчитанный прогноз из раздела 2.
