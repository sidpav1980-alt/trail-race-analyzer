# v0.0204
- Сундук в правом верхнем углу симуляции.
- Кошка выглядывает ровно 3 раза за гонку на 0,5 секунды реального времени.

- Можно получить до 3 дополнительных событий за гонку.
- Базовые события по длительности из v0.0203 сохранены.
