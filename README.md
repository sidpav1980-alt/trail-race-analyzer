# Trail Race Analyzer v0.54 — OFFLINE FULL

Это офлайн-PWA версия на базе v0.53.

## Что работает без интернета
- загрузка и анализ GPX самой гонки;
- фактическое moving/elapsed time из GPX;
- Trail Difficulty, набор/сброс, km-effort;
- три тренировочных GPX и калибровка;
- прогноз времени и темпа;
- HR-прогноз;
- стартовый список XLSX/CSV и локальные расчёты;
- сохранённые локально данные.

## Что требует интернет
- новый анализ карты OSM/Overpass;
- AI/OpenRouter и любые сетевые запросы.

Если анализ карты был сделан ранее онлайн и сохранён на этом iPhone, приложение может использовать сохранённый результат офлайн.

## Как установить на iPhone
1. Один раз открой эту версию через HTTPS-хостинг.
2. Дождись полной загрузки.
3. Safari → «Поделиться» → «На экран Домой».
4. После установки открой приложение один раз при интернете.
5. Далее основные расчёты работают без сети.

Важно: просто открыть `index.html` из приложения «Файлы» недостаточно для нормальной PWA-установки — service worker на iPhone требует HTTPS (или локальный web-server).
