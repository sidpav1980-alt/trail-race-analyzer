
# Trail Race Analyzer — iPhone Offline

Полностью автономная PWA-версия для iPhone.

Работает без сервера после установки/первой загрузки:
- GPX;
- профиль, набор и сброс;
- описание покрытия;
- пульсовая стратегия;
- XLSX/CSV стартовые списки;
- анализ соперников;
- вероятность победы / TOP‑3 / TOP‑5;
- локальное сохранение расчёта;
- скриншоты тренировок.

## Скриншоты и распознавание
Чтобы приложение не зависело от интернета и тяжёлой OCR-модели, используйте встроенный в iPhone Live Text:
1. Откройте/выберите скриншот.
2. Скопируйте распознанный iOS текст.
3. Вставьте его в поле рядом со скриншотом.
4. Нажмите «Заполнить из текста».

Приложение само вытащит из вставленного текста дистанцию, набор и пульс там, где формат распознаётся.

## Установка на iPhone
PWA всё равно нужно один раз открыть по HTTPS:
1. Разместите папку на GitHub Pages / Netlify / Vercel / Cloudflare Pages.
2. Откройте сайт в Safari.
3. Поделиться → На экран Домой.
4. После первого открытия основные файлы приложения кэшируются и приложение работает без сети.

## XLSX
В этой версии нет CDN и SheetJS. Встроен минимальный XLSX-парсер для обычных стартовых таблиц:
- первый лист;
- текстовые и числовые ячейки;
- shared strings;
- стандартное ZIP/Deflate-сжатие.

Сложные Excel-файлы с формулами/макросами/нестандартной структурой лучше сохранить как CSV.
