# v0.70

## Симуляция на телефоне
- Убран второй дублирующий график движения.
- Профиль GPX, белый индикатор положения и бегун теперь находятся в одном общем блоке.
- На iPhone метрики уложены в 3×2, управление не перекрывает текст.
- События и карта бродов показываются компактно в двух колонках.
- Нижний дублирующий блок итогов скрыт на экране симуляции: основное виртуальное время уже видно сверху.

## Анализ карты
- Реализован настоящий жёсткий тайм-аут 20 секунд через Promise.race.
- На 20-й секунде запрос отменяется, поздний ответ больше не может перезаписать интерфейс.
- Сразу появляется сообщение о тайм-ауте и кнопка «Повторить анализ карты».
