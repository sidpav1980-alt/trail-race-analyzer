# Trail Runner: Armageddon — Online 1.1

Онлайн-версия на Node.js без сторонних runtime-зависимостей.

## Возможности
- регистрация и вход по нику/паролю;
- серверная сессия;
- серверное сохранение игрового прогресса;
- локальная копия прогресса как резерв;
- синхронизация после изменений;
- `/api/health` для проверки сервера;
- вся игровая логика офлайн-версии 1.1 сохранена.

## Запуск
```bash
npm start
```
После запуска откройте `http://localhost:3000`.

## Render
В проекте есть `render.yaml`. Для постоянного хранения JSON-базы подключён диск в `/opt/render/project/src/data`.
Если хостинг не предоставляет постоянный диск на выбранном тарифе, замените хранилище на PostgreSQL перед публичным запуском.
