# Trail Runner: Armageddon — Online 1.0

Онлайн-версия с регистрацией и входом по нику/паролю.

- Регистрация нового игрока.
- Вход ранее зарегистрированного игрока.
- Сохранение игрового прогресса на сервере.
- Восстановление прогресса после повторного входа.
- Все актуальные игровые изменения перенесены в ветку с номером приложения 1.0.
