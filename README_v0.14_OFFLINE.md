# Trail Race Analyzer v0.14 OFFLINE

Полностью локальная версия для iPhone/Android/компьютера после установки PWA или открытия из локального веб-сервера.

## Работает без интернета
- загрузка и обработка GPX трассы;
- дистанция, набор/сброс и профиль высоты из GPX;
- загрузка стартового списка XLSX/CSV;
- ручной ITRA PI;
- три эталонные GPX;
- обязательный VO₂max;
- прогноз времени и рекомендуемого темпа по участкам;
- итоговый расчёт и локальное сохранение.

## Модель v0.14
- «Гоночная (плоская) GPX» должна быть не менее 10 км;
- реальный результат плоской GPX — главный скоростной эталон;
- результат масштабируется на дистанцию гонки по кривой Riegel;
- до ~25 км используется показатель 1.06;
- на более длинных дистанциях показатель постепенно увеличивается;
- рельеф калибруется по силовой и быстрой трейловым GPX;
- VO₂max используется как небольшая корректировка, а не как основной источник темпа;
- на плоской трассе первые километры не замедляются искусственно: стартовый запас около 1%;
- для длинных гонок после ~2 часов добавляется дополнительный коэффициент выносливости.

## Не работает без интернета
- OpenStreetMap / Overpass анализ покрытия;
- автоматический поиск бродов по OSM;
- AI-поиск ITRA;
- ChatGPT/OpenAI API.

Поэтому кнопка «прогноз с анализом GPX/OSM» в офлайн-версии скрыта. Обычный прогноз по трассе и трём эталонным GPX работает локально.

## Установка
Лучший вариант на iPhone — один раз открыть сайт этой сборки через HTTPS и добавить его на экран «Домой». После первого открытия service worker кэширует статические файлы, и приложение может запускаться без сети.
