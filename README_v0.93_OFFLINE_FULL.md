# Trail Race Analyzer v0.93 OFFLINE FULL

Офлайн-сборка на базе v0.92.

Работает без интернета:
- загрузка и анализ GPX трассы;
- профили высоты;
- ITRA-сложность/локальные расчёты;
- «Лучшая тренировка» с ручными полями;
- три GPX для общей модели прогноза;
- Силовая трейловая GPX;
- Быстрая трейловая GPX;
- Гоночная (плоская) GPX;
- прогноз по GPX гонки;
- VO₂max (необязательное ручное поле);
- пульсовая стратегия;
- локальная обработка стартового списка;
- итоговые расчёты.

Не работает без интернета:
- серверный OCR скриншотов;
- OSM-анализ карты/покрытия;
- AI-загрузка ITRA для стартового списка.

Для iPhone удобнее один раз открыть приложение через HTTPS и добавить на экран «Домой» — service worker кеширует основные файлы, после чего локальные функции работают без сети.
